# SEO Rules (MVP)

## Per-page checks
- ❌ Missing title
- ⚠️ Title too long / short
- ❌ Missing meta description
- ❌ Missing H1
- ⚠️ Multiple H1
- ❌ Images without alt
- ❌ Broken links
- ⚠️ No canonical
- ⚠️ Noindex detected

## Site-level aggregation
- % pages with issues
- Total errors / warnings
- Health score (0–100)

## Scoring
- Base: 100
- Error: -5
- Warning: -2
- Minimum: 0

## Issue codes (suggested)
- TITLE_MISSING
- TITLE_LENGTH
- META_MISSING
- H1_MISSING
- H1_MULTIPLE
- IMAGE_ALT_MISSING
- LINK_BROKEN
- CANONICAL_MISSING
- NOINDEX
