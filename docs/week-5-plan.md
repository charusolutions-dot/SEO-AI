# Week 5 Execution Plan — Reports + PDF Export + UX Polish

## Goal
By end of Week 5, you will have:
- Auto-generated SEO reports per scan
- Downloadable PDF reports
- Optional shareable report link
- Clean, client-ready report design
- UX polish across the app

## Report Content
### Cover
- Brand/logo
- Website URL
- Scan date
- Site health score

### Summary
- Site score
- Total pages scanned
- Errors / warnings / info
- Overall grade (Excellent / Good / Needs improvement / Poor)

### Charts
- Issues breakdown (donut)
- Score (large visual)
- Optional score trend

### Key Issues
- Top 10 errors
- Top 10 warnings
- Page URL, message, severity

### Pages Overview
- URL
- Page score
- Errors count
- Warnings count

### Footer
- “Generated by CodexSEO” (or brand)
- Date

## Report Generation Pipeline
**Recommended (MVP):** HTML report template → PDF

Flow:
```
User clicks "Download Report"
→ Backend fetches scan data
→ Render HTML report template
→ Convert HTML → PDF
→ Store in S3/local
→ Return download URL
```

Tools:
- HTML template via Jinja2 or React SSR
- PDF via Playwright, WeasyPrint, or wkhtmltopdf

## Backend Endpoints (Week 5)
- `POST /scans/{id}/report` → generate report
- `GET /scans/{id}/report/status` → pending/ready/failed
- `GET /reports/{id}` → download PDF

## Database (reports table)
- `id`
- `scan_id`
- `file_url`
- `status` (pending/ready/failed)
- `created_at`

## UX Polish
- Loading states (“Generating report…”) + toasts
- Disable buttons while busy
- Confirmation modals for destructive actions
- Empty states (“No scans yet”)
- Consistent spacing, typography, and icons

## Performance & Reliability
- Cache report data
- Avoid regeneration if report exists (unless forced)
- Timeout handling for PDF generation
- Background job for report generation

## Day-by-day breakdown
- Day 1: report layout + content definition
- Day 2: report data aggregation + HTML template
- Day 3: PDF generator integration + storage
- Day 4: frontend report actions + status UI
- Day 5: UX polish + empty states
- Day 6: test with real scans + PDF fixes
- Day 7: final QA + MVP demo prep
